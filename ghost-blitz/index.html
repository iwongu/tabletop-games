How to Play Ghost Blitz

There are 5 objects, each with its own true color: White Ghost, Green Bottle, Red Chair, Blue Book, and Grey Mouse.

Rule 1 — Exact Match: If one object on the card is shown in its true color (e.g., a White Ghost), tap that object immediately!
Rule 2 — Nothing Matches: If neither object is in its true color, tap the one object whose shape AND color are both completely missing from the card!

Example: Card shows a Blue Ghost + Red Bottle. Shapes shown: Ghost, Bottle. Colors shown: Blue (Book), Red (Chair). Only Grey Mouse has neither its shape nor its color on the card → tap Mouse!
