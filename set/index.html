How to Play SET

Every card has 4 features, each with 3 variations:

  • Color: Red, Green, or Purple
  • Shape: Diamond, Squiggle, or Oval
  • Count: 1, 2, or 3 symbols
  • Shading: Solid, Striped, or Open
The Golden Rule: Pick 3 cards where each of the 4 features is either all the same or all different. Never 2-and-1!
